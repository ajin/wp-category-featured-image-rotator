# Changelog

Each `## <version>` section becomes the notes of the matching GitHub release.

## 0.2.0

- Existing posts: you can now narrow the list to a category (including its
  subcategories) or a range of publish dates, and choose which posts get an
  image. Each post in the list shows what happened to it. You can still add
  images to all matching posts at once.

## 0.1.1

- Clearer wording for the setting that hides the featured image on the post
  page. It now reads "Don't show the featured image on the post", and its
  description explains that it only applies to images the plugin added.

## 0.1.0

First release.

- New posts get a featured image from the images you've picked for their
  category. The images take turns, so your posts don't all get the same one.
  You can shuffle them instead.
- They're regular WordPress featured images, so they work with your theme,
  SEO plugins and social sharing, and they stay if you remove the plugin.
- A post that already has a featured image is never changed. If you remove
  an image from a post after publishing, it won't be added again.
- Everything is set up in Posts → Featured Images: pick images for each
  category, set default images, and choose which category wins when a post
  is in more than one.
- Optional settings: use a photo that's already in the post, or don't show
  the featured image on the post page.
- Existing posts: find older posts without a featured image and add one to
  them.
- Works on WordPress 6.4 and newer with PHP 8.0 and newer, including
  multisite.
